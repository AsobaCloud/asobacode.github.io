# Guides Overview

Comprehensive guides covering all aspects of Zorora, from installation to advanced workflows.

## What You Can Find Here

This section provides step-by-step guides for:

- **Installation** - Get Zorora up and running on your system
- **Configuration** - Configure models, endpoints, and API keys
- **Terminal REPL** - Master the command-line interface
- **Web UI** - Use the browser-based research interface
- **Research Workflow** - Deep dive into deep research capabilities
- **Code Generation** - Generate code with Codestral
- **Development Workflow** - Multi-step code development with `/develop`
- **Slash Commands** - Complete command reference

## Quick Start

If you're new to Zorora, start here:

1. **[Installation](/guides/installation)** - Install Zorora and set up prerequisites
2. **[Configuration](/guides/configuration)** - Configure models and endpoints
3. **[Terminal REPL](/guides/terminal-repl)** - Learn the command-line interface
4. **[Research Workflow](/guides/research-workflow)** - Run your first research query
