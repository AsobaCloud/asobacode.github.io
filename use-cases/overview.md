# Use Cases Overview

Real-world examples and use cases for Zorora.

## What You Can Find Here

This section provides practical use cases demonstrating how Zorora can be used in real-world scenarios:

- **Academic Research** - Deep research for academic papers and literature reviews
- **Code Development** - Multi-step code development with `/develop` workflow
- **Multi-Source Analysis** - Cross-referencing claims across multiple sources
- **Energy Data Exploration** - EDA with production solar time series data

## Common Scenarios

### Research Scenarios

- **Literature Reviews** - Comprehensive research on a topic
- **Fact-Checking** - Verify claims across multiple sources
- **Trend Analysis** - Track developments over time
- **Comparative Analysis** - Compare different approaches or solutions

### Development Scenarios

- **Feature Addition** - Add new features to existing codebases
- **Code Refactoring** - Improve code structure and quality
- **Bug Fixes** - Identify and fix issues
- **Test Generation** - Create unit tests for code

### Analysis Scenarios

- **Claim Verification** - Verify claims across sources
- **Consensus Identification** - Find areas of agreement
- **Disagreement Analysis** - Identify conflicting views
- **Source Credibility** - Evaluate source reliability
