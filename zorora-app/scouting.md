# Scouting

Kanban pipeline for tracking brownfield, greenfield, and BESS opportunities through five evaluation stages — from initial identification through investment decision. Each stage includes automated feasibility studies across production, trading, grid, regulatory, and financial dimensions.

## Evaluation Stages

| Stage | Description |
|-------|-------------|
| **Identified** | New opportunity discovered via [Discovery](/zorora-app/discovery) or manual entry |
| **Scored** | Automated scoring across production, trading, grid, regulatory, and financial dimensions |
| **Feasibility** | Detailed feasibility study with Nehanda v3 synthesis |
| **Diligence** | Deep Research diligence report with cited sources |
| **Decision** | Investment decision — proceed, defer, or reject |

---

## Key Features

- **Five-stage Kanban pipeline** — drag opportunities between stages
- **Automated feasibility studies** — production, trading, grid, regulatory, and financial analysis
- **Brownfield, greenfield, and BESS** — track all opportunity types
- **One-click diligence** — launch a [Deep Research](/zorora-app/deep-research) report from any opportunity
- **Pipeline analytics** — see conversion rates and bottlenecks across stages
